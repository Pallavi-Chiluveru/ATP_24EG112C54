# 🚀 Week 06: Full-Stack MERN Integration

Welcome to **Week 06** of the ATP Capstone project. This week represents the culmination of previous learning, focusing on building a functional **Full-Stack Mini-Application** using the **MERN** stack (MongoDB, Express, React, Node.js).

## 📂 Project Structure

The project is organized into a clean client-server architecture within the `mini-app` directory.

### 💻 Backend (Node.js & Express)
A robust RESTful API designed to manage employee data with persistent storage.
- **`server.js`**: The main entry point, configuring middleware (CORS, JSON parsing) and establishing the MongoDB connection.
- **`API/`**: Contains `EmployeeAPI.js`, which defines the routing logic for CRUD operations.
- **`model/`**: Houses the Mongoose `Employee.js` schema, defining the structure of employee documents in the database.
- **Environment Management**: Utilizes `.env` for secure configuration of database credentials and server ports.

### 🎨 Frontend (React & Vite)
A dynamic, component-based user interface featuring seamless navigation and state management.
- **Routing**: Implements `react-router-dom` for a Single Page Application (SPA) experience.
- **Components**: Includes `CreateEmp`, `ListOfEmps`, `EditEmployee`, and `Home` for the core management workflow.
- **Assignments**: Dedicated routes for specific tasks (`ass1` through `ass7`) exploring advanced React patterns.
- **Layouts**: Uses `RootLayout` for consistent navigation and header elements across pages.
