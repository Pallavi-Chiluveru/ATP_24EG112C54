# 🚀 Week 04: HTML & CSS Fundamentals

Welcome to the documentation for **Week 04** of the ATP Capstone project. This week focused on mastering the core building blocks of web development: **HTML5** structure and **CSS3** styling.

## 📂 Project Structure

The `Week_04` directory contains hands-on assignments designed to practice semantic HTML and basic layout techniques.

| File | Description |
| :--- | :--- |
| `Assignment1.html` | Basic HTML structure, text formatting, and lists. |
| `Assignment2.html` | Structured profile page with ordered/unordered lists and embedded media. |
| `css_asign2.css` | External stylesheet for layout positioning and image styling. |

---

## 🛠️ Assignment Overviews

### 📝 Assignment 1: Web Page Basics
This project focuses on the fundamental tags required to create a functional web page.
- **Concepts Covered**:
  - Document Type Definition (`<!DOCTYPE html>`)
  - Text Formatting (`<b>`, `<i>`)
  - Headings (`<h1>`)
  - Hyperlinks (`<a>`)
  - Unordered Lists (`<ul>`, `<li>`)
  

### 🐱 Assignment 2: Pochi the Cat Profile
A more advanced implementation that combines structural HTML with external styling to create a professional-looking profile page.
- **Key Features**:
  - **Semantic Sections**: Organized using headings and div containers.
  - **List Variations**: Uses both ordered lists (`<ol>`) for profiles and unordered lists (`<ul>`) for external links.
  - **Embedded Assets**: Includes high-quality visual representation using Base64 encoded images.
  - **Styling**: Leverages `css_asign2.css` for:
    - Responsive image sizing.
    - Floating layouts for side-by-side content.
    - Decorative elements like `border-radius`.
# html
HTML is a markup language that is used to create web pages.
# css
CSS is a styling language that is used to style web pages.


    ## 🎨 Design System

The styling in this week's assignments emphasizes clarity and visual hierarchy.
- **Typography**: Focused on readability using standard browser fonts with strategic bolding and italics.
- **Layout**: Introduced CSS properties like `float` and `margin` to control element positioning.
- **Aesthetics**: Applied modern touches like rounded corners (`border-radius`) to interface elements.

---

## 📈 Learning Outcomes

By completing these assignments, the following competencies were developed:
1. Writing clean, valid **HTML5** code.
2. Implementing **External CSS** for separation of concerns.
3. Understanding the difference between **Ordered** and **Unordered lists**.
4. Managing page layout using basic CSS positioning techniques.
