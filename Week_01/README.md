# Week 01: JavaScript Fundamentals & Array Operations

This directory contains the assignments and exercises completed during the first week of the SUNTEK JavaScript training. The focus was on basic JavaScript syntax, functions, and array manipulations.

## Directory Structure

```text
Week_01/
├── A_01_Basicquestionss/       # Basic JavaScript Exercises
│   ├── greatestNumberFunctionQues5.js
│   ├── largestOfThreeNumbersQues2.js
│   ├── largestOfTwoNumbersQues1.js
│   ├── searchElementIndexQues7.js
│   ├── smallestInArrayQues4.js
│   ├── sumOfArrayFunctionQues6.js
│   └── sumOfMarksQues3.js
├── A_02_EmployeeArrayOperations/ # Advanced Array Operations (Objects)
│   ├── insertEmployeeQues8.js

└── README.md
```

## Folder Details

### 1. A_01_Basicquestionss
This folder contains solutions to basic algorithmic problems using JavaScript.

- **`largestOfTwoNumbersQues1.js`**: Compares two numbers and identifies the larger one.
- **`largestOfThreeNumbersQues2.js`**: Compares three numbers to find the maximum.
- **`sumOfMarksQues3.js`**: Calculates the total sum of elements in an array.
- **`smallestInArrayQues4.js`**: Finds the minimum value in a given array.
- **`greatestNumberFunctionQues5.js`**: A function-based approach to find the greatest number.
- **`sumOfArrayFunctionQues6.js`**: A reusable function to calculate the sum of array elements.
- **`searchElementIndexQues7.js`**: Searches for a specific element in an array and returns its index.

### 2. A_02_EmployeeArrayOperations
This folder focuses on manipulating arrays of objects, specifically managing employee records.

- **`insertEmployeeQues8.js`**: Demonstrates how to insert a new employee record into a specific position in the array.
- **`removeEmployeeQues9.js`**: Shows how to remove an employee record from the array based on certain criteria.
- **`updateEmployeeMarksQues10.js`**: Handles updating the marks or details of an existing employee in the array.

## How to Run
To execute any of these files, ensure you have [Node.js](https://nodejs.org/) installed, and run the following command in your terminal:

```bash
node A_01_Basicquestionss/*.js

node A_02_EmployeeArrayOperations/*.js
```
