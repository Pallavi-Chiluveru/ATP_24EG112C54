### 🧩 Assignment 2: Flexbox Card Systems
Implemented a responsive card system using CSS Flexbox. This assignment demonstrates how to align text and images dynamically, ensuring a consistent UI across different screen sizes.
* flexbox is a one-dimensional layout model that allows you to arrange items in rows or columns. 
* flex-direction: row | row-reverse | column | column-reverse;
* flex-wrap: nowrap | wrap | wrap-reverse;
* justify-content: flex-start | flex-end | center | space-between | space-around | space-evenly;
* align-items: flex-start | flex-end | center | stretch | baseline;
* align-content: flex-start | flex-end | center | stretch | space-between | space-around | space-evenly;
## conclusion
flexbox is a powerful tool for aligning and distributing items in rows or columns and controlling the alignment and distribution of those items.
